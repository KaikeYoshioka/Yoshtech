Sobre

A YoshTech é uma loja virtual de eletrônicos criada como trabalho acadêmico do curso de Análise e Desenvolvimento de Software. Na vitrine você encontra notebooks, periféricos, fones, smartphones, wearables, games, armazenamento e redes, tudo cadastrado e mantido por uma API REST.

O front-end usa HTML, Bootstrap 5.3 e JavaScript puro, e conversa com a API (Node.js, Express, Sequelize e SQL Server) somente via fetch.
